Form: Sighting.

Capture where and when a bird was seen and its observed state.

- Coordinates: latitude in [-90, 90], longitude in [-180, 180]; only if spoken.
- Times (observedTime, startTime, endTime) as HH:mm; never assume midnight.
- Ring positions (upperRight, upperLeft, lowerRight, lowerLeft) and leg colours
  (leftLeg, rightLeg) only if the ring or colour is explicitly stated.
- species and ringingMorphs are references: extract the spoken lookup key only.
- Record cause of death or decomposition only if the bird was described as dead.
- physicalCondition: fill only the traits actually described.
- Set photoMentioned true only if a photo or picture is explicitly mentioned.
